# 🧮 Calculadora Web

A clean, modern, and fully responsive calculator built with **HTML**, **CSS**, and **vanilla JavaScript**. It supports both mouse/touch clicks and keyboard input, providing a smooth user experience across devices.

![Made with HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![Made with CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![Made with JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Features

- ➕ Basic arithmetic operations: addition, subtraction, multiplication, and division
- ⌨️ Full keyboard support (numbers, operators, `Enter`/`=`, `Backspace`, `Escape`)
- 🧹 Clear (`AC`) and single-character delete (`DEL`) functionality
- 🔢 Decimal point support with duplicate-decimal prevention
- 🚫 Division-by-zero handling with an `Error` display
- 🔟 Automatic number formatting with thousands separators
- 📱 Responsive design that adapts to mobile screens
- 🎨 Sleek dark-themed UI with smooth hover and click animations

## 🚀 Getting Started

No build tools or dependencies are required — this is a pure front-end project.

### Run Locally

1. Clone or download this repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate into the project folder:
   ```bash
   cd <project-folder>
   ```
3. Open `index.html` in your favorite web browser:
   ```bash
   open index.html   # macOS
   start index.html  # Windows
   ```

That's it — no server or installation needed!

## 🖱️ Usage

| Action              | Mouse/Touch         | Keyboard              |
|---------------------|----------------------|------------------------|
| Enter a number       | Click number buttons | `0`–`9` keys           |
| Enter a decimal      | Click `.`             | `.` key                |
| Choose an operation   | Click `÷ × − +`       | `/ * - +` keys         |
| Calculate result      | Click `=`             | `Enter` or `=`         |
| Delete last digit     | Click `DEL`           | `Backspace`            |
| Clear everything      | Click `AC`            | `Escape`               |

## 🛠️ Built With

- **HTML5** – Semantic structure of the calculator
- **CSS3** – Flexbox & CSS Grid for layout, gradients and transitions for styling
- **JavaScript (ES6)** – Object-oriented logic using a `Calculator` class
